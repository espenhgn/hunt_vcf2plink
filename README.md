# README

Misc. Slurm job scripts for file format conversion, etc. of HUNT vcf files to PLINK2 (pgen) and PLINK1 (bed) format.

## Files

1. ``vcf2pfile.sh`` - Slurm job script to convert vcf (with GP field as in HUNT vcf files) to PLINK2 (pgen) format.
2. ``align_ids.sh`` - Slurm script that creates pfiles with "chrom:pos:ref:alt" variant ids aligned to the given reference genome sequence in fasta format. Indels and non atcg variants will be dropped. Keeps SNPs.
3. ``merge_chr.sh`` - Slurm script that merges per-chromosome files generated by ``align_ids.sh`` script
4. ``plink2_liftover.sh``: slurm script for mapping PLINK2 file set from genomic build hg19/GRCh37 to GRCh38 using triple-liftover utility
5. ``align_ids_toGRCh38.sh`` - same as above on GRCh38 file set
6. ``merge_chr_GRCh38.sh`` - same as above on aligned GRCh38 file set
7. ``pca/inhouse_pca_insample.sh``: slurm job script for computing PCA scores in sample
8. ``pca/calculate_pc.sh``: slurm script for computing eigenvectors/values in independent sample (not used)
